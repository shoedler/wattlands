# Changelog: audio-tank

- Torque Company: the Drive seat's cylinders no longer sound like a toy as they top out. Each firing is now a dull thump with a body, each valve a dull knock with four takes that vary from stroke to stroke, and neither winds up in pitch as you speed up. The three cylinders stay unequal and every stroke stays on the crank. The gun's sounds are untouched.
- Torque Company: the diesel you see on the tank now fires with the one you hear. It has the same three cylinders as its machine card, each piston tops out on its stroke, and a spark lights a bore only as it fires.
