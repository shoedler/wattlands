# Changelog: siege

- Scaffolded from the template with tools/new_game.
- G0: Generator Siege's manifest, contracts (state, inputs, intents, events, snapshot, content), the Castellum Rotae map, shift plans with wave offsets, the Overdrive state machine, and a minimal module that plays every shift end to end.
- G2: balance pass. Bounties at 0.3x, threat budget 13, a 130 HP gate, slower rams (0.75 m/s), dearer towers (65 / 52 / 45), a 2.2 s Ballista and a 7-damage Scorpion: 1- and 2-rider teams no longer breach every wave, a full team scores an A instead of an S, and tower riding pays about half the generator.
