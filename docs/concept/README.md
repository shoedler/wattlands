# Concept art

These images come from `tools/concept_art/wattlands_concept_art.py`, generated on fal.ai.

- File names follow `<concept>_<style>_<model>[_<tag>].jpg`.
- `manifest.json` records each image's prompt, model, request id and estimated cost.
- `index.html` shows all the images side by side.

The images are reference for the build: palette, shapes and mood. They are not shipped assets.
