# Code of conduct

Wattlands is a game for riding with friends. The project should feel the same way.

Be kind and assume good faith. Criticize work, not people. Welcome newcomers, whatever their experience, fitness, age, background or identity.

Not okay: harassment, insults, sexual attention or imagery, personal attacks, publishing someone's private information, comments about a person's body or fitness, and anything else that would make someone reasonably feel unwelcome.

This applies in issues, pull requests, discussions and anywhere you speak for the project.

If something's wrong, tell the maintainer privately: use [GitHub's private reporting](https://github.com/shoedler/wattlands/security/advisories/new) and say it's a conduct report. Reports are kept confidential. The maintainer may edit or remove comments, and may warn or ban someone from the project. If the report is about the maintainer, use [GitHub's abuse form](https://github.com/contact/report-abuse).

These rules borrow their spirit from the [Contributor Covenant](https://www.contributor-covenant.org/), which is worth reading.
